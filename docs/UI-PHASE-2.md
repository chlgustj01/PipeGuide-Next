# UI/UX 2단계

기준 커밋: `74dbdc7`의 독립 UI MVP. 작업 시작 시 로컬에 있던 인트로·선체 시각물 변경도 유지했다. 기존 모듈 계약과 테스트는 삭제하지 않았으며, 실제 도메인 기능·설계 데이터·좌표 코드를 이식하지 않았다. 이번 작업에서 commit/push를 수행하지 않는다.

## 화면

| 모드 | 상단 KPI 4개 | 우측 상황형 패널 |
| --- | --- | --- |
| 탐색 | 도면 수 / 인식 완료 / 연결 후보 / 승인 연결 | 도면 선택, OCR 결과, Line ID·근거, 연결 상태·승인/거부, 3D 생성 가능 여부 |
| 문제 검토 | 미해결 문제 / 간섭 / 이격 부족 / 개정 필요 | 선택 배관, 관경 변경, 연결 도면, 간섭·이격 검사, 문제 구간을 유지한 경로 개선 진입 |
| 경로 개선 | 최소 이격 / 간섭 / 경로 길이 / 굽힘 수 | 문제 구간, 후보 A/B/C, 기존·선택 후보 비교, 적용·기록 영역 |

프로젝트 선택·변경 이력·설정은 공통 헤더에 둔다. 새 상단 작업 탭은 만들지 않는다. 데이터가 없을 때는 `—`, 검사를 하지 않았을 때는 `미검사`로 표시한다. 아직 실행할 수 없는 버튼에는 disabled와 사유를 제공한다. A/B/C는 빈 선택 슬롯이며 후보 경로나 수치를 생성하지 않는다.

공통 WebGL 캔버스와 renderer는 main.js에서 한 번 생성하고, 모드 전환 시 KPI와 패널 DOM만 갱신한다. 반응형 변경·패널 접기는 동일 캔버스의 크기만 변경한다. 세로 메뉴·검색·하단 대상 탭·인트로는 유지한다. 패널 내부만 스크롤되고 KPI와 뷰포트의 위치는 유지된다. 760px 이하에서는 처음에 우측 패널을 접고, 접기/열기 버튼을 제공한다.

## 상태와 향후 응답 연결

- `src/state.js`: 기존 보기·모드 UI 상태 그대로 유지.
- `src/workspace-state.js`: 프로젝트/배관/문제/후보 컨텍스트, 모드별 KPI와 패널 응답 상태.
- `src/workspace-panels.js`: 현재 상태를 KPI·접이식 패널로 표시.
- `src/workspace.css`: 2단계 배치와 작은 화면 접기 UI.

main.js의 `modeWorkspace.data`가 명시적 연결 지점이다. 지금은 어댑터를 호출하거나 실제 응답을 생성하지 않는다.

1. 프로젝트 모듈에서 받은 목록을 `setProjects([{id,name}, ...])`로 전달하고 `selectProject(id)`를 사용한다. 기본 목록은 비어 있다.
2. 실제 선택 이벤트에서 `selectPipe(id)`, `selectIssue(id)`를 사용한다. 모드 변경은 이 컨텍스트를 지우지 않는다.
3. 응답 바인딩은 `applyMetrics(mode, values, context)`, `applyPanel(mode, patch, context)`를 사용한다. context에는 projectId, 선택 배관이 필요한 경우 pipeId, 경로 개선에서는 issueId가 포함된다. 패널 응답에는 source도 필수다. 현재 선택과 다른 오래된 응답은 무시한다.
4. KPI 레코드는 `{status: 'ready'|'unavailable'|'unchecked', value, unit, source}`다. ready는 실제 숫자·출처가 있어야 하며 거리·길이는 명시적 단위가 필요하다. 실제 출처가 있는 0과 데이터 없음은 구분한다.
5. 패널은 모드별 문서/OCR/근거/관경/연결 도면/기준 경로/후보 비교 필드를 받는다. 후보는 최대 3개이며 실제 응답으로 받은 ID만 선택할 수 있다. 선택 후보의 지표도 응답값만 표시한다.
6. 프로젝트·배관·문제 변경 시 종속 결과를 무효화한다. 적용·승인·검사·관경 변경·이력 저장 로직은 구현하지 않았고 비활성화 상태다. 빈 변경 이력에 모드 전환이나 예시 결과를 기록하지 않는다.

## 검증

- `npm test`: 기존 15개 유지 + 상태 경계 7개 = 22개 통과.
- `npm run check`: 통과. 기존 모듈 계약/테스트 유지, 외부 리소스·레거시 전역 참조 없음.
- 브라우저: 세 모드 KPI/패널 변경, 미연결/미검사 표시, disabled 사유, 2D 보기·대상 탭 유지, 공통 캔버스 1개, 패널 접기/열기, 공통 이력·설정 확인.
- 390×844 작은 화면에서 기본 패널 접힘과 열기/닫기 확인. 테스트 후 뷰포트 크기 복원.
- 콘솔 오류 0. 모델이나 가짜 프로젝트·배관·검사·승인·후보 수치를 UI에 삽입하지 않음.

변경 파일: `index.html`, `src/main.js`, `src/workspace-state.js`, `src/workspace-panels.js`, `src/workspace.css`, `tests/workspace-state.test.mjs`, `README.md`, 이 문서. 인트로 변경은 앞선 작업의 미커밋 변경이며 이번 단계에서 제거하지 않았다.
