## 추가: 네온 LNG 탱커 인트로

사용자 요청에 따라 초기 화면을 추가했다. 기존 워크스페이스와 기능 계약은 유지한다. `src/intro/ship-visual.js`(단위 없는 시각용 탱커), `renderer.js`(독립 WebGL·수평 회전·네온 블러 합성), `intro.js`(진입·복귀·일시 정지·모션 감소), `intro.css`(인트로 배치)로 분리했다. index.html과 main.js는 화면 진입만 연결한다. 런타임 라이브러리·CDN·기존 선박 메시를 추가하지 않았다.

- 테스트 12개 통과: 기존 9개 + 시각용 형상의 유한 버퍼·독립성·카메라 행렬 3개
- 정적 검사 통과: JS 14개, 인라인 코드·외부 HTML 리소스·레거시 전역 없음
- 브라우저: 인트로 초기 표시, 네온 렌더링, 회전/일시 정지, EXPLORE SHIP 진입, 워크스페이스의 모델 없음 상태, 문제 검토 미연결 상태, 인트로 복귀 확인
- 브라우저 콘솔 오류 0
- 기존 워크스페이스의 설계 모델·데이터는 여전히 없음. 인트로 시각물은 모듈에 등록되거나 전달되지 않는다.

### 인트로 선체 정교화

`src/intro/hull-visual.js`로 선체 곡면을 분리하고, 기울기를 제한한 Hermite 단면 보간과 192×48 표면 분할을 적용했다. 별도 구체였던 벌브는 선수·외판과 이어지는 단일 표면으로 재구성했다. 선미 마감, 실제 표면을 따르는 갑판·난간, 탱크 끝단과 외부 계단도 추가했다. 첨부 이미지의 비율을 기준으로 한 시각 모델이며 원본 3D 자산의 동일 복제나 실제 설계 형상이 아니다.

추가 검증: 테스트 15개 통과(선체 대칭·연속성·보간 범위 포함), 정적 검사 JS 16개 통과, 브라우저 렌더링·진입 전환 확인. 기존 데이터 모듈과 워크스페이스에는 변경 없음.
