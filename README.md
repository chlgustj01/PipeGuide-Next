# PipeGuide-Next

기존 PiPeGuide의 전역 런타임·설계 좌표와 독립된 선박 배관 워크스페이스. HTML·CSS·ES 모듈을 분리했고 외부 패키지·CDN 없이 실행합니다. 기능 이식 1단계에서 검증한 PidDB 엔진과 읽기 전용 참고 DB만 별도 모듈로 포함합니다.

## 실행

Node.js 20 이상에서 실행합니다. 의존성 설치는 필요 없습니다.

```sh
npm run dev
```

브라우저에서 `http://127.0.0.1:4190`을 엽니다. ES 모듈을 사용하므로 파일 더블클릭 대신 HTTP 서버로 실행하세요. 서버는 로컬 인터페이스에만 바인딩됩니다. 정적 호스팅에는 `index.html`과 `src/`를 함께 올립니다.

## 검증

```sh
npm test
npm run check
```

## 포함한 UI

- 첫 화면: 청록·자홍 네온 LNG 탱커의 독립 WebGL 인트로. 수평 자동 회전·드래그 회전·일시 정지·모션 감소 설정을 지원하며 EXPLORE SHIP으로 기존 워크스페이스에 진입합니다. 헤더의 선박 아이콘으로 인트로에 돌아갈 수 있습니다.
- 세로 작업 메뉴: 탐색 · 문제 검토 · 경로 개선
- 공통 WebGL 뷰포트, UI용 방향 표시와 입체/평면 보기
- 검색의 데이터 없음 안내, 배관·장비·공간 탭, 필요할 때 여는 작업·설정 패널
- 키보드 검색(`/`), 패널 닫기(`Esc`), 뷰포트 방향키·초기화(`Home`)
- 독립 모듈 계약 7개와 등록·호출·취소 인터페이스

실제 설계 모델·GA 좌표·전역 선박 치수·장비 위치·독립 네트워크 3D·경로 계산·검사는 포함하지 않았습니다. PidDB 연결 판정·승인과 도면 참조 메타데이터는 DB를 열 때만 연결됩니다. 초기 어댑터 등록은 0개이며 DB를 열면 2개가 연결됩니다. 인트로의 탱커는 `src/intro`에서만 사용하는 단위 없는 시각물입니다. 가짜 검사 결과나 설계 좌표를 표시하지 않습니다.

구조: `index.html`(마크업), `src/styles.css`(표현), `src/main.js`(UI 조립), `src/state.js`(UI 상태), `src/viewport.js`(빈 WebGL 뷰포트), `src/modules/`(기능 경계).

UI/UX 2단계: 모드별 KPI 4개와 상황형 작업 패널, 공통 프로젝트·변경 이력·설정, 작은 화면 패널 접기를 추가했습니다. 값이 없는 KPI는 `—` 또는 `미검사`로 표시하며 실제 응답을 받을 상태 경계만 준비했습니다. [화면 구성·응답 연결·검증 기록](docs/UI-PHASE-2.md)

기능 이식 1단계: 탐색 패널에서 **ZIP 참고 DB 열기**를 누르면 PidDB의 실제 연결 판정 엔진을 사용합니다. 기본 시연 5장은 후보 11건이며, 후보 선택 후 근거·승인·거부·되돌리기를 사용할 수 있습니다. 원본 DB는 읽기 전용이며 검토 기록은 DB 해시별로 브라우저에 별도 저장합니다. JSON DB도 선택할 수 있습니다. 인식 완료와 3D 모델은 여전히 미연결입니다. [API·판정 결과·회귀 검증](docs/PIDDB-MIGRATION-1.md)
